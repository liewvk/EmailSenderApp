# EmailSenderApp

A C# application for sending emails.

## Features

- Simple and intuitive email sending interface
- Support for email composition and delivery

## Getting Started

### Prerequisites

- .NET Framework or .NET Core
- Visual Studio or any compatible C# IDE

### Installation

1. Clone the repository
```bash
git clone https://github.com/liewvk/EmailSenderApp.git
```

2. Open the project in Visual Studio

3. Build and run the application

## Usage

Launch the application and follow the on-screen instructions to compose and send emails.
